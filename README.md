# mytnotes

**my**training**notes** — also read as “mighty notes.” Social habit builder: structured plans (not bare labels like “25 push-ups”) with exercises, guidance, reminders, and optional community.

## Platforms

Website, phone (iOS/Android), smartwatch (Apple Watch, Garmin).

## Core concepts

| Term | Meaning |
|------|---------|
| **Activity** | One habit unit (e.g. single-leg squat). Users can fork and customize; public variants ranked by popularity/recency for adoption. |
| **Program** | Named bundle of activities. Subscribe to others’ programs or compose your own. |
| **Studio** | Authoring UI to create/edit activities and attach the features below. |

### Activity attachments

| Feature | Purpose | Alt names (optional) |
|---------|---------|----------------------|
| **Notes** | Links and references (form, articles). | Resources |
| **Sets** | Recommended prescription (e.g. 3×3, 3×/week). | Prescription, schedule |
| **Reminders** | User-defined times; repeat daily/weekly/monthly/etc.; multiple per day. | — |
| **Coach call** | Non-reminder nudges: motivation, education, phase/state (e.g. fasting window). | Coaching moments |
| **Scoring** | Progress against defined objectives. | Objectives, metrics |

## Social (full vision)

- Comments/Q&A on activities and programs (progress, motivation, questions).
- Follow friends or local users.
- **Later:** scheduled group sessions (Peloton-style slots for simultaneous habit blocks).
- Rewards and profile achievements when others adopt your activity or program.

## Roadmap (product)

1. **Solo-first** — Excellent for one person; no empty “social ghost town.”
2. **Close circle** — Pairs and small groups; social features that work with few users.
3. **Platform** — Broader follow graph, discovery, group classes after critical mass.
4. **Launch content** — Curated activities/programs (weight loss, running, strength, etc.).
5. **Portable programs** — Import/export format to ship a large initial library and let power users share.
